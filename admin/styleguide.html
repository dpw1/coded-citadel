CCSTYLE UI Kit

A dark, dependency-free component library. Every class is prefixed CCSTYLE__ and follows BEM, so it can be dropped into any project without colliding with existing styles.

Getting started

Copy ccstyle.css into your project and link it. It ships its own tokens, so nothing else is required. The Inter and Oswald webfonts are optional — without them the kit falls back to the system sans-serif. 

<link rel="stylesheet" href="./ccstyle.css" />
<body class="CCSTYLE__body"> … </body>

Naming convention

Strict BEM. A block is a standalone component, an element is a child that only makes sense inside that block, and a modifier changes appearance or state.

PatternExampleMeaning
CCSTYLE__block CCSTYLE__card The component root.
CCSTYLE__block__element CCSTYLE__card__title A child of the component.
CCSTYLE__block--modifier CCSTYLE__btn--primary A variant. Always applied alongside the base class.
Rule of thumb for agents: never use a modifier on its own. class="CCSTYLE__btn CCSTYLE__btn--primary" is correct; class="CCSTYLE__btn--primary" will render unstyled.

Design tokens

Everything is driven by custom properties on :root. To re-theme the kit for another product, override the tokens — never the rules.

Surfaces

Four stacked greys. Use them in order to express depth: page background, then panels/toolbars, then cards, then anything raised above a card (like a sticky table header).

--CCSTYLE-bg-basePage background
--CCSTYLE-bg-surfacePanels, toolbars
--CCSTYLE-bg-cardCards, modals
--CCSTYLE-bg-raisedSticky headers

Brand & semantic

Amber is the only brand colour and it carries all emphasis. The semantic colours are reserved for meaning — never decoration.

--CCSTYLE-primaryBrand, active state
--CCSTYLE-successConfirmations
--CCSTYLE-dangerErrors, destructive
--CCSTYLE-warningCaution
--CCSTYLE-infoNeutral info
--CCSTYLE-text-mutedSecondary text

Radius, elevation, motion

Radii step 6 / 10 / 14px plus a pill. Shadows are tight and dark rather than wide and soft, which keeps panels crisp on a near-black background. All transitions share one easing curve so the whole UI feels like one piece. 

--CCSTYLE-r-sm: 6px;      /* chips, small buttons */
--CCSTYLE-r-md: 10px;     /* inputs, buttons */
--CCSTYLE-r-lg: 14px;     /* cards, tables, modals */
--CCSTYLE-r-pill: 999px;  /* chips, badges, progress */

--CCSTYLE-shadow-sm: 0 1px 2px rgba(0,0,0,.3);
--CCSTYLE-shadow-md: 0 6px 18px -6px rgba(0,0,0,.55);
--CCSTYLE-shadow-lg: 0 18px 48px -12px rgba(0,0,0,.7);

--CCSTYLE-ring: 0 0 0 3px rgba(255,153,0,.22);   /* focus */
--CCSTYLE-ease: cubic-bezier(.22,.61,.36,1);     /* every transition */

The two decoration tokens

Flat dark panels look dead, so every surface layers a near-invisible top-down sheen (--CCSTYLE-surface) over its background colour and a 1px inner highlight along the top edge (--CCSTYLE-hairline). This is what makes cards read as physical rather than painted on. 

background: var(--CCSTYLE-surface), var(--CCSTYLE-bg-card);
box-shadow: var(--CCSTYLE-shadow-sm), var(--CCSTYLE-hairline);

Typography

Two families. Oswald (condensed, uppercase) for titles, KPI numbers and anything that should feel like signage. Inter for everything you actually read. Body copy is never uppercase.

Buttons

All buttons are uppercase, letter-spaced and lift 1px on hover. The base CCSTYLE__btn is a neutral grey button; add a modifier for intent. 

<button class="CCSTYLE__btn CCSTYLE__btn--primary">Primary</button>
<button class="CCSTYLE__btn CCSTYLE__btn--outline">Outline</button>
<button class="CCSTYLE__btn CCSTYLE__btn--ghost">Ghost</button>
<button class="CCSTYLE__btn CCSTYLE__btn--danger">Danger</button>
VariantLooks likeUse for
--primary Solid amber gradient, dark ink, glowing shadow on hover The single most important action in a view
--outline Amber text on a faint amber tint with an amber border Secondary actions beside a primary, e.g. Refresh
--ghost Invisible until hovered, then a soft grey wash Toolbar and icon actions, low-emphasis controls
--danger Pale red text on a red tint Delete, revoke, reset — anything irreversible

Sizes

Three sizes plus full-width and icon-only. --icon is a square button and always needs an aria-label. 

<button class="CCSTYLE__btn CCSTYLE__btn--primary CCSTYLE__btn--sm">Small</button>
<button class="CCSTYLE__btn CCSTYLE__btn--primary CCSTYLE__btn--lg">Large</button>
<button class="CCSTYLE__btn CCSTYLE__btn--block">Full width</button>
<button class="CCSTYLE__btn CCSTYLE__btn--icon" aria-label="Refresh">&#8635;</button>

Chips & badges

Chips are interactive filters — rounded pills that fill with amber when selected. Badges look similar but are static labels you cannot click. Keep the two visually distinct in your markup by using buttons for chips and spans for badges.

Forms

Controls sit on a barely-lighter translucent fill with a grey border. On focus the border turns amber and a soft 3px amber ring appears — the same ring is used for keyboard focus everywhere in the kit, so focus always looks identical.

Fields

CCSTYLE__field stacks an uppercase CCSTYLE__label above its control. Selects get a CSS-drawn chevron so they match across browsers. 

<label class="CCSTYLE__field">
  <span class="CCSTYLE__label">Name</span>
  <input class="CCSTYLE__input" type="text" placeholder="e.g. BETA-CREATORS" />
  <span class="CCSTYLE__hint">Must be unique.</span>
</label>

<!-- rounded search variant -->
<input class="CCSTYLE__input CCSTYLE__input--search" type="search" />

<!-- invalid state -->
<input class="CCSTYLE__input CCSTYLE__input--invalid" />
<span class="CCSTYLE__hint CCSTYLE__hint--error">Must be at least 1.</span>

Checkbox & switch

The checkbox is the native control tinted amber. The switch is a 38px track whose knob slides right and turns amber when checked — use it for settings that apply immediately, and a checkbox for anything you submit. 

<label class="CCSTYLE__check">
  <input class="CCSTYLE__check__input" type="checkbox" /> Requires login
</label>

<label class="CCSTYLE__switch">
  <input class="CCSTYLE__switch__input" type="checkbox" />
  <span class="CCSTYLE__switch__track"></span>
  <span>Live mode</span>
</label>

Form shell

CCSTYLE__form is a padded panel that wraps a row of fields and wraps them responsively, aligned along their bottom edge so labels of different lengths still line up.

Cell helpers. __num right-aligns and uses tabular figures so columns of numbers line up. __mono renders truncated monospace ids. __sort turns a header into a button and appends an arrow from its aria-sort value.

Navigation

Tabs

Horizontal uppercase tabs with a 2px amber underline on the active item. Best for three to six peers at one level. 

<div class="CCSTYLE__tabs" role="tablist">
  <button class="CCSTYLE__tab CCSTYLE__tab--active" role="tab" aria-selected="true">Analytics</button>
  <button class="CCSTYLE__tab" role="tab" aria-selected="false">Users</button>
</div>

Collapsible sidebar

A full-height rail for many destinations grouped by product. Each item carries a monogram badge, and the current item is marked by a glowing amber pill on the left edge. Groups reveal their children by animating max-height, so expansion is smooth rather than instant.

Accessibility & motion

Every interactive component exposes the same amber focus ring via :focus-visible. All hover lifts, the modal animation and the spinner are disabled under prefers-reduced-motion: reduce.
