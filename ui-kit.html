Gradients

Kept subtle. Surface and hairline are near-flat; accent is only for primary CTAs; glow sits behind the hero.

Buttons

Flat, quiet primary on .CC__home (tint + border). Icon modifiers use ::before — no extra markup. Chrome uses src/assets/chrome.svg; Instagram uses src/assets/instagram.svg. React pages can still use ChromeIcon with CC__btn__icon.

Modifiers: CC__btn--chrome-extension · CC__btn--instagram

<button class="CC__btn CC__btn--primary CC__btn--chrome-extension">Add to Chrome</button>
<a class="CC__btn CC__btn--outline CC__btn--instagram" href="#instagram">View on Instagram</a>

Agent rules

  • Edit tokens, not values. Change src/styles/ui-kit.css; never hardcode hex, px radius, shadows or durations in page CSS.
  • One accent. Orange only. --CC__color-success is for live status and positive deltas.
  • Named radius steps. Use --CC__radius-lg / -xl, not calc() on the base radius.
  • Oswald titles, Inter body. Use --CC__font-display for headings and display numbers only.
  • Button icons. CC__btn--chrome-extension and CC__btn--instagram prepend SVG in CSS; in React you can use ChromeIcon with CC__btn__icon.
  • Homepage is scoped. Refreshed styling lives under .CC__home. Other routes still use legacy styling — migrate them with this kit.
  • Every interactive element needs a visible focus state and a 44px minimum tap target.
