# How to Find Fast-Growing YouTube Videos in the Last 7 Days

**Quick answer:** Set **Publish date → Last 7 days**, add a **views per day** minimum that fits your niche, then sort by **views per day**.

I use YouTube for research every week, and the native filters always felt like a half solution.

---

## What YouTube lets you do today

YouTube’s “Upload date” filter has presets, but not views/day or channel-size combos on the same screen.

---

## How to do it with YouTube Filter Pro

1. Run a normal YouTube search for your topic.
2. Click **Filter** next to the search bar (YouTube Filter Pro).
3. Set the filters described below in the modal (Video or Channel tabs).
4. Click **Search** in the footer and open **View Results** when the panel appears.
5. Leave the tab open while the extension scans more results (complex filters can take up to a minute).

**Publish date:** Last 7 days. **Views per day:** set a minimum (start around 100–500 for smaller niches).

---

## Example workflow

Query `indie game dev log` with 7 days + 300 views/day min surfaces active devlogs worth commenting on.

---

## Tips and common mistakes

### Broad queries need higher floors

On `music` try higher views/day mins or add title includes.

### Use pause

Pause the results panel if you want to inspect a page without fetching more.

---

## FAQ

### Is last 7 days exact?

It uses the extension’s publish presets aligned to calendar windows.

### Why leave the tab open?

Filtering continues as YouTube loads more search pages.
